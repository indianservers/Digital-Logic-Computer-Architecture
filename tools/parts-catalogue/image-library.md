# Reusable anatomy image library

1002 stable part IDs are linked to 144 distinct images. Device-specific INS and SONAR artwork takes priority. Original anatomy content remains intact.

Images are representative educational examples, not model-specific purchase specifications. A functional label can represent circuitry integrated into a shared board. Component-family reuse does not imply physical interchangeability.

New illustrations were created with the built-in ImageGen tool. Recorded prompts and output paths are in [generated-image-prompts.json](./generated-image-prompts.json). The initial enclosure and radio module illustrations used briefs for an open electronics enclosure with mounting screws/standoffs and a shielded RF transceiver PCB with SMA connector, respectively. Full-resolution sources stay intact; WebP copies are delivery previews.
