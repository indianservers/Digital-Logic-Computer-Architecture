1. Simulation contract
   Engineering tools → Accuracy: modeled behavior, reset and limits; export contract.

2. Architecture eligibility
   Accuracy: severity-grouped actual graph findings and locate actions.

3. Wiring-driven execution
   Strict graph execution; explicit controller IR/PC/Z wires; negative rewiring regression tests.

4. Four-state execution
   Live 0/1/X/Z wires and benches; strict active-input faults. Architectural storage is numeric and cannot retain X/Z.

5. Clock-edge consistency
   Clock alternates low/high; rising action advances microcycle. Step advances instruction, Run advances microcycles; common engine.

6. Explicit reset policy
   Builder: clear data or preserve separate data memory. Contest always clears data/reloads source.

7. Independent correctness oracle
   Contest: separate BigInt reference execution and flag semantics; assembler/decoder shared.

8. Reference coverage disclosure
   Accuracy and contest capability matrix: eligible register-file CPUs versus assertion-only architectures.

9. ALU truth tables
   Component Library benches and boundary tables; arithmetic/reference regressions across supported widths.

10. Memory semantics
   Memory System permissions, capacities and word offsets; Timing & ISA documents addressing and scope.

11. Instruction legality
   ISA validation, assembler diagnostics and unknown-opcode execution faults.

12. Branch semantics
   Timing & ISA: PC masking, jump and signed relative branch explanation and example.

13. Real timing modes
   Timing & ISA: instruction versus FSM microcycle; explicitly no physical gate-delay model.

14. Reproducible runs
   Contest: version, configuration, reset-state graph, seed, execution/suite hashes and traces.

15. Golden regression fixtures
   Accuracy: five executable template assertions; automated negative designs and engine regression tests.

16. Larger working canvas
   Focus Canvas/F6 hides hero and outer panels; Hide Panels expands canvas further.

17. Resizable panels
   Palette/inspector size sliders; vertically resizable canvas; responsive stacking.

18. Readable toolbox cards
   Illustrated/Compact palette toggle; compact widths use two-column cards.

19. Useful component tooltips
   Each toolbox component exposes functional contract, timing and allowed widths.

20. Search by function
   Search indexes behavior/category with storage and selector aliases.

21. Recent and favorite components
   Builder palette filters; recent insertion history and existing Library favorites.

22. Compatible-port highlighting
