Lab 128 — Barcode Scanner

Capture. Decode. Connect.

Illumination exposes a printed barcode.

Device overview

Illumination exposes a printed barcode. A lens focuses reflected light on a sensor; the analog front end and ADC produce samples. Decoding validates symbol widths and the checksum before sending a value through USB or wireless. This lab encodes and reads an Code 128 teaching symbol with a verified checksum.

◈ Scan Path (Optical Principle)

◈ Step-by-Step Working Principle

  1. Start a local optical acquisition.

  2. Illuminate dark bars and light spaces.

  3. Measure their reflected intensity.

  4. Focus the reflection onto the sensor.

  5. Identify Code 128 module patterns and verify its checksum.

  6. Publish the decoded number after validation.

  7. Show success or a failed read.
