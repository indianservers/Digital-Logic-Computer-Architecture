◈ Working Principle (Step by Step)

  1. Measure a synthetic obstacle range and vehicle motion.

  2. Combine wheel motion with available position information.

  3. Choose steering and forward-speed demands.

  4. Steering changes yaw rate while wheels advance the platform.

  5. Compare obstacle distance with the braking threshold.

  6. Brake forward motion when the safety rule requires it.

◈ Key Takeaways

✓ Camera and range sensing observe the ground environment

✓ GNSS and wheel odometry support position estimates

✓ Steering angle and wheelbase determine turning rate

✓ Guidance commands traction and steering separately

✓ An obstacle supervisor can brake forward travel

✓ The source is a recovered vehicle image.

✓ Bicycle kinematics omit tyre slip and suspension.

✓ Braking is a local teaching rule.
