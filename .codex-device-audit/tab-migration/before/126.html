Device overview

Touch, accelerometer, gyro and optical pulse sensors feed a low-power SoC. Firmware filters measurements and detects events, then updates the OLED, vibration motor and wireless sync. The pulse model generates synthetic optical samples; no health measurement is taken.

◈ Step-by-Step Working Principle

  1. Tap, move or select a sensor demonstration.

  2. Collect synthetic touch, motion and pulse readings.

  3. Suppress noise and estimate useful measurements.

  4. Firmware decides which event occurred.

  5. Present measured state on the OLED.

  6. Provide tactile feedback for user actions.

  7. Transfer the local sensor record to the sync display.

  8. Use scheduled sensor sampling to reduce consumption.
