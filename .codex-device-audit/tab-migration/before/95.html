◈ Signal / Data Flow

  1. 1Capture image or template
  2. 2Preprocess and extract features
  3. 3Compare with enrolled reference
  4. 4Apply permission and threshold
  5. 5Pulse relay and record event
  6. 6Optional network report

◈ Working Principle (Step by Step)

  1. Choose a synthetic fingerprint, face or card.

  2. Extract a numerical teaching template.

  3. Compare the template with the enrolled reference.

  4. Apply the threshold and credential policy.

  5. Pulse the virtual relay and record the decision locally.
