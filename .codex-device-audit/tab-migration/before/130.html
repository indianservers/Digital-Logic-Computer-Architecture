Lab 130 — Biometric Fingerprint Scanner

Capture. Identify. Grant Access.

Optical or capacitive sensors capture ridge patterns.

Device overview

Optical or capacitive sensors capture ridge patterns. Processing extracts minutiae and compares their geometry with an enrolled template. A threshold determines the access decision. This lab uses deterministic synthetic minutiae and a distance-based matcher; it stores no real fingerprint.

◈ Step-by-Step Working Principle

  1. Start with a synthetic fingerprint sample.

  2. Capture a noisy ridge/minutiae representation.

  3. Extract surviving synthetic feature coordinates.

  4. Measure the distance from enrolled minutiae.

  5. Compare the score with the selected threshold.

  6. Issue an access signal only after the match step.
