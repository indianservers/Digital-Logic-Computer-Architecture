Lab 107 — Dynamic Positioning System

Maintain position and heading using sensors, computers and thrusters.

◈ What is it?

Position references, a heading sensor, wind sensors and a motion reference unit feed the DP computer. A reduced surge/sway/yaw controller estimates environmental forces and allocates corrective force to thrusters. Feedback updates position and heading. The teaching model includes bounded thrust and a loss-of-thruster case.

◈ Working Principle (Step by Step)

  1. Read position, heading and environmental measurements.

  2. Compute error from the station-keeping setpoint.

  3. Determine required surge, sway and yaw correction.

  4. Distribute demanded force among available thrusters.

  5. Thrusters change vessel motion.

  6. Measured vessel response closes the loop.

◈ Key Takeaways

✓ Multiple sensors feed a closed-loop DP computer

✓ Position and heading remain near commanded setpoints

✓ Thrust allocation distributes surge, sway and yaw demand

✓ Feedback corrects wind, current and wave disturbances

✓ Available thrust limits position-holding performance

✓ Reduced three-degree-of-freedom dynamics.

✓ Thruster saturation limits station keeping.

✓ No vessel commands are issued.
