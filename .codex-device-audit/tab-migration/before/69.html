AVIATION SYSTEMS · LAB 69

Radar Altimeter

True Height. Greater Safety.

Transmit and receive antennas face the terrain. An FMCW transmitter sweeps frequency; mixing the delayed return with the transmitted signal creates a beat frequency proportional to height: h = c × fᵦ / (2 × sweep slope)

Start Learning →

◈External Parts

Estimate height above terrain from the delay or frequency difference of reflected radio signals.

◈Internal Components (Exploded View)

Inspect components and functions

RF synthesizer: Generates the controlled microwave sweep used as the height-measurement reference.

◈How It Works — 6 Steps

  1. Sweep a microwave signal toward the ground.

  2. Receive the terrain echo through a separate antenna.

  3. Mix transmit and delayed receive signals.

  4. Convert beat frequency to height above ground.

  5. Send height and validity to aircraft systems.

  6. Repeat and supervise signal quality.

◈Real-World Applications

  • Autoland
  • Terrain awareness
  • Flare control
  • Helicopter low-altitude operations
  • UAV operations

◈Safety / Limitations

  • Blocked or damaged antennas can invalidate height.
  • Terrain reflectivity and attitude affect the received signal.
  • Radio height differs from barometric altitude.

◈Key Takeaways

  • Transmit reference starts the signal path.
  • Height DSP supports AGL height.
  • Valid acquisition and supervision are required for trustworthy outputs.
