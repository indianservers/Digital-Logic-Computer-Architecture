◈ Real Hardware / Device Overview

SLAM estimates robot pose while building a map from sensor observations. This reduced 2D lab combines biased odometry, ray-cast scans, occupancy updates and an optional landmark correction that limits accumulated error. It does not claim full graph optimization. A grid planner computes a collision-free route through the synthetic room.

◈ Working Principle (Step by Step)

  1. LiDAR rays, IMU and encoder motion provide measurements.

  2. Identify occupied endpoints from range measurements.

  3. Integrate odometry; optionally correct against a synthetic landmark.

  4. Accumulate free and occupied evidence in a grid.

  5. Search free cells from start to goal.

  6. Track successive path cells.
