◈ Input → Processing → Output

InputMeasurement→ProcessingConditioning + ADC→OutputDisplay / buzzer

1Measurement input

Protected probes capture voltage, current or resistance from the virtual test circuit. A selector chooses the correct divider, shunt or test-source path.

2Processing logic

Signal conditioning scales the input for the ADC. Measurement logic applies the selected conversion, input loading and range checks.

3Output reading

The LCD presents the converted reading. Continuity uses a resistance threshold; disconnected probes, an open current fuse and overload produce explicit indications.

◈ Simplified Circuit / Block Diagram

Selector routes one measurement path. Voltage: parallel; current: series; resistance: unpowered load.

◈ Safety Notices

✓ Choose the correct function and input terminals.

✓ Measure current in series and never place a current input across a voltage source.

✓ Resistance / continuity tests use an unpowered circuit.

✓ This lab demonstrates low-voltage virtual circuits.

✓ Physical instruments require their specified ratings and intact fuses.

◈ Key Takeaways

✓ Voltage and current use different input paths.

✓ A meter has finite input impedance.

✓ Resistance testing uses an internal source on an unpowered circuit.

✓ Continuity is a thresholded resistance measurement.
