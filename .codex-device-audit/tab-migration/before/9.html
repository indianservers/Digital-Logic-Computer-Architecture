Build This Device — System Architecture
  1. 1. Reader antenna

    The RF interface transmits or receives electromagnetic energy. Matching, switching and demodulation connect the physical link to digital processing.

  2. 2. RF front end

    A high-input-impedance front end amplifies the useful signal while reducing common-mode interference. Gain and headroom determine the sampling range.

  3. 3. NFC controller

    Firmware or a digital processor applies calibration, validates signal quality, computes the useful quantity and supervises the system state.

  4. 4. Secure element

    A secure credential stage supports authenticated protocol exchange. A payment token represents test credentials without exposing a real account number.

  5. 5. Credential token

    A secure credential stage supports authenticated protocol exchange. A payment token represents test credentials without exposing a real account number.

  6. 6. Processor

    Firmware or a digital processor applies calibration, validates signal quality, computes the useful quantity and supervises the system state.

  7. 7. Display

    The interface presents the processed quantity or stores acquired data with its timing and validity state.

  8. 8. Network interface

    Network interface connects to the acquisition or control chain. A reader creates a short-range RF field that couples to a phone or card antenna. Protocol exchange and secure credential processing communicate a payment token to the payment system.

Supervision: Invalid credential invalidates the affected signal chain. The processor must check signal quality before presenting a result or enabling an output.
