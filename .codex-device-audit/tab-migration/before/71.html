1030 MHz receiver: Receives interrogations from ground surveillance or airborne collision-avoidance equipment.

◈How It Works — 6 Steps

  1. Acquire the ground interrogator’s 1030 MHz pulses.

  2. Identify the interrogation type.

  3. Select identity, pressure-altitude or addressed data.

  4. Format the requested reply.

  5. Send the coded reply at 1090 MHz.

  6. ATC associates the reply with its surveillance track.

◈Safety / Limitations

The receiver decodes 1030 MHz interrogations. Control logic selects a Mode A identity, Mode C pressure-altitude or Mode S addressed reply and transmits on 1090 MHz. Squawk digits are octal. This page shows a simplified pulse reply; it does not transmit RF.

  • Only digits 0–7 are valid in a four-digit squawk.
  • Pressure-altitude reporting requires valid encoder data.
  • This simulator emits no real radio signal.
