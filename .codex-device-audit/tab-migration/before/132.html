Device overview

Germanium optics collect long-wave infrared radiation onto a microbolometer array. Calibration, reflected-temperature and emissivity compensation convert radiance into an estimated temperature map. A false-colour palette visualizes that map. The local model uses a broadband fourth-power approximation, rather than a calibrated camera response.

◈ Sensing Principle

◈ Step-by-Step Working Principle

  1. Objects emit temperature-dependent radiation.

  2. IR optics collect the radiance.

  3. Microbolometer resistance changes with absorbed energy.

  4. An internal reference supports drift correction.

  5. Compensate using assumed emissivity and reflected temperature.

  6. Map temperatures to colours and a display.
