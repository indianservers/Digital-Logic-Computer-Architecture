◈ What is it?

Pilot commands travel through the tether to an underwater control computer. IMU and pressure measurements support stabilization and depth hold. ESCs drive thrusters; camera and telemetry data return to the topside console. The reduced model exposes surge, yaw, depth, lights and a virtual manipulator.

◈ Working Principle (Step by Step)

  1. Pilot sets movement commands.

  2. The tether carries commands and power/data.

  3. The onboard computer uses sensor feedback.

  4. ESCs change thruster demand.

  5. Video and telemetry travel to the surface.

  6. Pilot evaluates the simulated scene.

  7. Depth and attitude loops correct motion.

  8. Continuous command and feedback keep the ROV responsive.

◈ Key Takeaways

✓ ESCs control thrusters and auxiliary actuators

✓ Video and telemetry return to the pilot

✓ Tethered reduced teaching platform.

✓ Manipulator and lighting are virtual.

✓ No real vehicle or camera connection.
