Build This Device — System Architecture
  1. 1. Air-data computer

    Firmware or a digital processor applies calibration, validates signal quality, computes the useful quantity and supervises the system state.

  2. 2. Inertial sensors

    Air-data and inertial measurements estimate aircraft state. Validity checks precede the guidance and feedback calculations.

  3. 3. Flight-control computer

    Firmware or a digital processor applies calibration, validates signal quality, computes the useful quantity and supervises the system state.

  4. 4. Mode-control panel

    Mode-control panel connects to the acquisition or control chain. A feedback controller compares the desired aircraft state with sensor estimates. Corrective actuator commands reduce error while respecting the simplified model’s limits.

  5. 5. Servo actuators

    A driver converts a controller command into motion. Encoder, force or current feedback closes the loop and reveals stalled or overloaded operation.

  6. 6. Control surfaces

    Control surfaces connects to the acquisition or control chain. A feedback controller compares the desired aircraft state with sensor estimates. Corrective actuator commands reduce error while respecting the simplified model’s limits.

  7. 7. Data bus

    Data bus connects to the acquisition or control chain. A feedback controller compares the desired aircraft state with sensor estimates. Corrective actuator commands reduce error while respecting the simplified model’s limits.

Supervision: Air-data sensor fault invalidates the affected signal chain. The processor must check signal quality before presenting a result or enabling an output.

◈Real-World Applications

✦

Flight guidance

Selected targets are compared with measured aircraft state to generate control commands.

◉

Cruise stabilization

Feedback reduces deviations in a simplified steady-flight model.

◇

Heading / altitude control

Mode selection determines whether altitude, heading or vertical speed is the active target.
